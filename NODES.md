# Floret Nodes

Every built-in NodeDef, grouped by category. Generated by hand from
`src/nodes/**` — keep in sync when adding or renaming nodes.

Format per row:

| Label · `type` | Inputs → Outputs | Description |

Port types: `number`, `boolean`, `string`, `vec2`, `color`, `mat3`,
`layer`, `style`, `audio`, `image`, `any`. A trailing `*` marks a spread-kind port.

**Pin kinds** — three flavours, distinguished visually:
- *single* (default): round pin, accepts one wire.
- *spread*: round pin, accepts one wire carrying a list.
- *multi* (input only): **taller pill-shaped pin**, accepts N wires; the
  runtime gathers them into a spread. Used by `transform/group` so you
  can drop many layer wires onto one input without a Stack chain.

`audio` is a persistent handle to a live p5.sound object kept alive in
the audio registry across frames. Wires of this type carry signal flow:
Source nodes (Oscillator, Noise, …) emit it; Processors (Filter, Gain,
…) consume and re-emit a processed version; the **Output** sink
terminates the chain. Per-frame compute updates parameters on the
existing audio object — the Web Audio nodes themselves only get
re-created when the node type changes or the editor node is deleted.

## Random

Seeded, deterministic noise and PRNGs. Wire `time/frame` into `seed` for per-frame variation, or a `region/foreach` iteration index for one value per slot.

**Patch seed** (native app): every seeded node — these, the spread shufflers / noise / Game of Life seed / random walk, Wind and Turbulence, Emitter and FromLayer, WalkerCluster and the LFO's random shapes — mixes the patch's seed into its own (`EvalCtx::seed`, `floret_engine::seed`). Seed 0, the default, leaves every node's seed as it is; **Vary** (Ctrl/⌘+Shift+R) re-rolls it for a new variation of the same patch. The seed and saved **presets** live in the `.flora` file (optional top-level `seed` / `presets`) and are edited in the Presets panel.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **Noise** · `noise/noise` | `pos: vec2*`, `x, y, scale, seed, octaves, falloff, warp, warpScale: number*` (+ `feature: string` in cellular mode) → `noise: number`, `flow: vec2` | 2D noise at (pos + (x, y)) · scale, per element over spreads. `mode`: perlin, simplex, value, cellular (Worley; `feature` F1 / F2 / F2-F1) or curl (`flow` = curl of Perlin fBm). `octaves` > 1 = fBm, `falloff` = amplitude ratio; `warp` / `warpScale` domain-warp the point. Perlin mode at defaults equals the old Perlin node, curl mode the old CurlNoise. Native-only. |
| **Perlin** · `noise/perlin` | `x, y, seed, octaves, falloff: number` → `out: number` | 2D Perlin noise in [0, 1]. `octaves` > 1 yields fractal Brownian motion; `falloff` is the amplitude ratio between octaves (default 0.5). Hidden from the palette: use Noise. |
| **Uniform** · `random/uniform` | `min, max, seed: number` → `out: number` | Uniform random in [min, max). |
| **Gaussian** · `random/gaussian` | `mean, sd, seed: number` → `out: number` | Gaussian (normal) random with the given mean and standard deviation. |
| **Wanderer2D** · `random/wanderer2d` | `t, speed, area, seed: number` → `out: vec2` | A 2D point that drifts smoothly with Perlin noise, centred on (0, 0). Pure function of `t` — feed `time/seconds` for live drift. |

## Text

Native-only generative typography. Shaping (kerning, ligatures, Arabic and other scripts, right-to-left runs, combining marks) and font fallback happen in the engine; `text/glyphs` and `text/outline` lay text out exactly like `draw/text` given the same inputs, so their outputs sit on the drawn text.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **Font** · `text/font` | `family, file: string` → `font: string, loaded: boolean, axes: string*, axisMin, axisDefault, axisMax: number*` | An installed family (dropdown) or a font file (.ttf/.otf/.ttc/.woff/.woff2, picked or typed as a path; it wins). `font` goes into `style/text-params`. Lists the variation axes. |
| **Glyphs** · `text/glyphs` | `string, pos, size, align, spacing, style` → `shape: layer, glyphs: layer*, positions: vec2*, advances: number*, chars: string*, charIndex: number*` | Split text into shaped glyphs for kinetic type: per glyph a layer at the origin (translate it to its position), its baseline position, advance, characters and index. |
| **Text on Path** · `text/on-path` | `string, points: vec2*, path: layer, closed, size, offset, spacing, align, shift, style` → `shape: layer, glyphs: layer*, positions: vec2*, angles: number*` | Lay text along a polyline or a path layer; each glyph turns to the tangent. `offset` slides it along, `shift` lifts it off the path. |
| **Text Outline** · `text/outline` | `string, pos, size, align, spacing, mode, style` → `points: vec2*, contours, glyphs: number*` | Points every `spacing` units along the glyph outlines (`outline`) or on a grid inside them (`fill`), for particles from type and morphing. |
| **Text Animate** · `text/animate` | `text: layer*, progress, stagger: number, order, ease: string, offset: vec2, rotate, scale, opacity, seed: number` → `shape: layer, glyphs: layer*, amounts: number*` | Glyph-by-glyph animation without a ForEach, on `draw/text`, Glyphs or Text on Path. `in`: each glyph eases from its start state (moved by `offset`, turned by `rotate` radians, at `scale` and `opacity`) to its place as `progress` runs 0 → 1; `stagger` 0 moves all together, 1 one after another, in `order` (forward, backward, center, edges, random). Run `progress` 1 → 0 to animate out. `wave`: `progress` is a phase; glyphs swing by `offset` / `rotate` and towards `scale` / `opacity` on a sine, `stagger` cycles apart. Glyphs turn and scale about their centres; `amounts` is each glyph's eased progress (or wave), for colours or anything else per glyph. |

## State

Cross-frame memory. The runtime breaks the topo cycle for these — their write input is gathered post-tick and emitted on the next frame.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **State** · `state/value` | `init, next: any` → `current: any` | One slot of cross-frame state for a single value. `init` seeds tick 0; `next` captured at end-of-tick; `current` emitted next tick. |
| **State\*** · `state/spread` | `init, next: any*` → `current: any*` | Same, for spreads. Walker trails, GoL grids, particle states. |
| **Read** · `state/read` | `init: any` → `current: any` | Split-state pattern — left half. Emits the value last written to the same slot. Falls back to `init` on frame 0. Auto-numbered `slot` badge shows the pairing. |
| **Write** · `state/write` | `next: any` → — | Split-state pattern — right half. Stashes `next` under the slot at end-of-tick. The matching Read emits it on the next tick. |

**Read/Write vs. single State**: dropping a `State*` node puts both pins on the same box, which forces one wire to bend backward when you wire up feedback. `Read` + `Write` are the same mechanism rendered as two boxes — drop Read on the left of your patch and Write on the right, and feedback flows strictly left-to-right with no visible loop. The two halves are paired by the slot number on each header.

## Region

Regions are scope containers. Inner nodes run with extra context (per-iteration values, conditions, cache hashes) supplied by the orchestrator. Ports are added on the frame's edges by dragging wires onto them; the compile step synthesises the matching splicer-in / splicer-out at runtime.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **ForEach** · `region/foreach` | dynamic frame ports → dynamic frame ports | Iterate over a spread. Inner nodes run once per slot. |
| **If** · `region/if` | `condition: boolean` + dynamic ports → dynamic ports | Run the inner scope when `condition` is true; otherwise emit empties / forward accumulator inits unchanged. |
| **Cache** · `region/cache` | dynamic ports → dynamic ports | Memoise the inner scope by structural hash of its inputs. Re-runs only when inputs change. |
| **Read** · `region/accumulator-read/{number,boolean,image}` | `init: T` → `read: T` | Per-iteration accumulator read. Paired by `slot` with a Write inside the same region. Drop on the LEFT of the inner scope so wires flow rightward into the loop body. |
| **Write** · `region/accumulator-write/{number,boolean,image}` | `write: T` → `final: T` | Per-iteration accumulator write. The `write` input becomes the next iteration's `read`; the last value is exposed as `final` on the outer side once the loop completes. |

### Internal (hidden from palette)

These exist so the runtime has a node to schedule for each region frame port. Compile synthesises them; the user never drops one manually.

- `region/splicer-in/{number,layer,boolean}` — receive an outer spread; deliver one slot per iteration.
- `region/splicer-out/{number,layer,boolean}` — collect one value per iteration into an outer spread.

### Simulation

One stateful node with a `mode` dropdown; its pins follow the mode. It steps 60 times per second of frame time (at most 3 steps a frame), so the same seed and frame times give the same result. A rising edge on `reset` starts over; so does a new `seed` (and, per mode, a new size / count / grid). Native only. Samples: `sim-flocking`, `sim-slime-mould`, `sim-dla-coral`, `sim-cloth`.

## Geometry

Native-only generators and shape operations. The polygon nodes share their outputs: `shape` (all polygons in one layer), one layer per polygon, `points` (every ring's corners, flat) and `counts` (corners per ring — pair them with **AtGroup** to pick one ring). Layers are read as outlines: polygons, paths, lines, rects, ellipses, arcs, triangles, quads and glyphs (`text/glyphs`), with group transforms applied. A dropdown picks the mode; the pins follow it.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **Scatter** · `geometry/scatter` | `center, size: vec2, shape: layer*` + mode pins (`distance` / `count` / `spacing, jitter` / `points`), `relax`, `seed` → `points: vec2*` | Points over a rectangle or inside a wired shape. Modes: `poisson` (no two closer than `distance`), `random`, `jittered-grid` (one per `spacing` cell, moved up to `jitter` of a cell), `halton` (low-discrepancy, shifted by the seed), `relax` (the wired `points`). `relax` runs that many passes of Lloyd relaxation (each point to the centre of its Voronoi cell, up to 100): clumps and gaps even out into an organic, even spread with an exact count. Same seed, same points. |
| **Cells** · `geometry/cells` | `points: vec2*, center, size: vec2` (voronoi), `gap: number, colors: color*, style` → `shape: layer, cells: layer*, points: vec2*, counts: number*, centers: vec2*` | Voronoi cells (clipped to the rectangle), Delaunay triangles or the convex hull of a points spread. `gap` leaves space between neighbours; `colors` fills polygon i with colour i (cycled). |
| **Path Ops** · `geometry/path-ops` | `points: vec2*, closed: boolean, path: layer*` + mode pins (`spacing` / `iterations` / `tolerance` / `distance, join`), `style` → `shape: layer, layers: layer*, points: vec2*, counts: number*` | Reshape a point list or every outline of a layer. Modes: `resample` (even spacing), `smooth` (Chaikin), `subdivide` (midpoints), `simplify` (Ramer–Douglas–Peucker), `offset` (grow / shrink areas with round, miter or bevel joins; open paths shift sideways). Shapes from a layer keep their style unless `style` is wired. |
| **Shape Boolean** · `geometry/boolean` | `a, b: layer*, style` → `shape: layer, layers: layer*, points: vec2*, counts: number*` | `union`, `intersect`, `subtract` (a − b) or `xor` of the filled areas of two layers (nonzero winding; lines ignored), holes included. With only `a` wired, `union` merges its shapes. |
| **L-System** · `geometry/lsystem` | `axiom, rules: string, iterations, angle, step, fit: number, position: vec2, heading, jitter, seed: number, style` → `shape: layer, layers: layer*, points: vec2*, counts: number*` | Rewrite `axiom` by `rules` (`X=…`, separated by `;`) `iterations` times and draw it with a turtle: `F` `G` draw, `f` `g` move, `+` `-` turn by `angle`°, `\|` turns round, `[` `]` branch. `fit` > 0 scales the drawing into a `fit`-wide box centred on `position`. `jitter` randomises every turn (by `seed`). |
| **Trim Path** · `geometry/trim` | `points: vec2*, closed: boolean, path: layer*, start, end, offset: number, style` → `shape: layer, layers: layer*, points: vec2*, counts: number*, heads: vec2*, angles: number*` | Draw-on / write-on: only the part of each outline between `start` and `end` (0..1 of its arc length), slid round by `offset` (wraps; a closed path carries on round its start). Modes: `each` trims every outline at once; `sequence` lays them end to end and trims the run, so they draw one after another (handwriting glyph outlines). Pieces are lines: a filled shape strokes in its fill colour unless `style` is wired. `heads` / `angles`: where each drawing end is and which way it heads (one for `sequence`), for a pen tip or arrowhead. |
| **Shape Morph** · `geometry/morph` | `a, b: layer*, t, points: number, style` → `shape: layer, layers: layer*, points: vec2*, counts: number*` | Blend `a`'s outlines into `b`'s by `t` (0 = a, 1 = b). Outer shapes pair with outer shapes and holes with holes, in order; a contour with no partner shrinks to (grows from) its centre. Pairs are resampled to `points` each (0 = about one per 4 units) and lined up (same direction, best start point) so blends don't twist; open and closed mix. Fill / stroke colours and stroke weight blend too, unless `style` is wired. |
| **Connect Points** · `geometry/connect` | `points: vec2*` + mode pins (`distance, maxLinks` / `neighbours, distance`), `fade, taper: number, style` → `shape: layer, from, to: vec2*, strength: number*` | Lines between nearby points (plexus). `distance`: every pair closer than `distance`, each point keeping at most `maxLinks` (shortest first; 0 = no limit). `nearest`: each point to its `neighbours` nearest (within `distance` when > 0). `strength` falls from 1 (touching) to 0 (at the reach); `fade` takes that much off a line's alpha and `taper` off its width. A uniform grid keeps thousands of points fast; at most 100 000 lines. |
| **Contours** · `geometry/contours` | mode pins (`values: number*, cols` / `points: vec2*, radius: number*, cell` / `image`), `center, size: vec2, threshold, levels, step: number, style` → `shape: layer, layers: layer*, points: vec2*, counts: number*, levels: number*` | Isolines of a field as closed outlines (marching squares). `field`: a spread of `values`, `cols` a row, over the rectangle (e.g. noise on Grid positions: topographic lines). `points`: metaballs, Σ radius² / distance², sampled every `cell` units. `image`: brightness × alpha (0..1) of an image centred on `center` at `size` (0 = its pixel size). Draws `levels` contours at `threshold`, `threshold + step`, …; outside the field counts as low, so every contour closes, running clockwise round high ground: each level fills as one polygon with its holes. `levels` out: each contour's level. |
