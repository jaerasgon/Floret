# Nodule Nodes

Every built-in NodeDef, grouped by category. Generated by hand from
`src/nodes/**` — keep in sync when adding or renaming nodes.

Format per row:

| Label · `type` | Inputs → Outputs | Description |

Port types: `number`, `boolean`, `string`, `vec2`, `color`, `mat3`,
`layer`, `style`, `audio`, `image`, `any`. A trailing `*` marks a spread-kind port.

**Pin kinds** — three flavours, distinguished visually:
- *single* (default): round pin, accepts one wire.
- *spread*: round pin, accepts one wire carrying a list.
- *multi* (input only): **taller pill-shaped pin**, accepts N wires; the
  runtime gathers them into a spread. Used by `transform/group` so you
  can drop many layer wires onto one input without a Stack chain.

`audio` is a persistent handle to a live p5.sound object kept alive in
the audio registry across frames. Wires of this type carry signal flow:
Source nodes (Oscillator, Noise, …) emit it; Processors (Filter, Gain,
…) consume and re-emit a processed version; the **Output** sink
terminates the chain. Per-frame compute updates parameters on the
existing audio object — the Web Audio nodes themselves only get
re-created when the node type changes or the editor node is deleted.

## Transform

All transform nodes use `push`/`pop` so they don't leak state into sibling layers.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **Group** · `transform/group` | `layers: layer (multi)` → `out: layer` | Combine N Layer wires into one Layer. The `layers` pin is a tall pill — drop multiple wires straight onto it, no Stack chain required. Spread inputs also welcome (elements get appended). |
| **Translate** · `transform/translate` | `x, y: number, layer: layer` → `out: layer` | Translate an inner Layer by (x, y). |
| **Rotate** · `transform/rotate` | `angle: number, layer: layer` → `out: layer` | Rotate an inner Layer by `angle` radians. |
| **Scale** · `transform/scale` | `sx, sy: number, layer: layer` → `out: layer` | Scale an inner Layer by (sx, sy). |
| **ShearX** · `transform/shear-x` | `angle: number, layer: layer` → `out: layer` | Shear an inner Layer along the X axis by `angle` radians. |
| **ShearY** · `transform/shear-y` | `angle: number, layer: layer` → `out: layer` | Shear an inner Layer along the Y axis by `angle` radians. |
| **ApplyMatrix** · `transform/apply-matrix` | `a, b, c, d, e, f: number, layer: layer` → `out: layer` | Multiply the current transform by `[[a, c, e], [b, d, f], [0, 0, 1]]`. Defaults are identity. |
| **Blend** · `transform/blend` | `mode: string, layer: layer` → `out: layer` | Draw the inner Layer with a blend mode (add / multiply / screen / difference / overlay / …), then restore. Not a Style because p5's `blendMode` isn't saved by push/pop. |
| **Group** · `transform/group` | `layers: layer*` → `out: layer` | Combine a spread of Layers into a single Layer. Lets a single Transform reposition a whole ForEach result as one unit. |
| **Cache** · `transform/cache` | `layer: layer*, w, h: number` → `out: layer` | Rasterise a Layer (or spread) into a persistent offscreen canvas, then blit it each frame. Re-renders only when upstream inputs change — the runtime already memoises compute, so a stable layer chain stays bitmap-cached at ~0.07ms / frame regardless of how many primitives it contains. Massive speedup for static or rarely-updated scenes (ForEach grids, dense generative art, hand-drawn backgrounds). `w` / `h` default to 0 → match the active renderer's canvas size. Skip Cache for layers that change every frame — it would re-rasterise every frame and add overhead. |

## Image

Image manipulation. The `image` wire carries an `HTMLCanvasElement` — either loaded by `io/image-url`, derived by one of the nodes below, or rendered from a Layer via `image/from-layer`. Derived nodes own a persistent offscreen canvas per node id (via the derived-image registry) so the output bitmap is reused across frames.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **Dims** · `image/dims` | `image: image` → `width, height, aspect: number` | Pixel dimensions of an image. `aspect` is `width / height`. All zero while loading. |
| **Sample** · `image/sample` | `image: image, x, y: number` → `color: color` | Read one pixel as a Color. Coordinates clamp to the image bounds. |
| **SampleSpread** · `image/sample-spread` | `image: image, points: vec2*` → `colors: color*` | Read a spread of points from an image, one Color per point. One full-bitmap read amortised across all points — cheap for thousands. |
| **Crop** · `image/crop` | `image: image, sx, sy, sw, sh: number` → `image: image` | New image containing the source's `(sx, sy, sw, sh)` rectangle, sized `(sw, sh)`. Zero in `sw/sh` runs the rect to the image edge. |
| **Slicer** · `image/slicer` | `image, cols, rows: number` → `images: image*` | Split an image into a `cols × rows` grid of sub-images (row-major spread). Each sub-image is sized `(srcW/cols, srcH/rows)`. Capped at 256 cells. |
| **Resize** · `image/resize` | `image: image, w, h: number` → `image: image` | New image scaled to `(w, h)`. Zero on an axis keeps the source's dimension on that axis. |
| **Filter** · `image/filter` | `image: image, level: number` → `image: image` | Apply a p5 filter. `mode` param: gray / invert / threshold / posterize / blur / dilate / erode / opaque. `level` tunes threshold / posterize / blur. |
| **Blend** · `image/blend` | `a, b: image, sx, sy, sw, sh, dx, dy, dw, dh: number` → `image: image` | Composite B into A at `(dx, dy, dw, dh)` from B's `(sx, sy, sw, sh)` region with the chosen blend mode. `mode` param: normal / add / darken / lighten / difference / exclusion / multiply / screen / overlay / hard-light / soft-light / dodge / burn. Output sized to A. |
| **FromLayer** · `image/from-layer` | `layer: layer*, w, h: number` → `image: image` | Render a Layer (spread) into an offscreen p5.Graphics and emit it as an `image`. The bridge from drawing to data — unlocks feedback loops and using patch output as a texture. |

## Sound

Audio nodes wrap p5.sound. The `audio` wire type carries persistent
handles — each Source/Processor owns a Web Audio node that lives across
frames; per-frame compute updates params (freq, amp, cutoff, …) without
re-allocating. The audio chain terminates at **Output**, the sink.
First-user-gesture handling (browser autoplay policy) is automatic —
clicking anywhere in the page resumes the AudioContext.

### Sinks

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **Output** · `sound/output` | `in: audio, volume: number` → — | Audio sink. Connect a chain here to hear it. `volume` sets master output gain. |

### Sources

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **Oscillator** · `sound/oscillator` | `freq, amp: number` → `audio: audio` | Sine / triangle / saw / square wave. `type` param swaps shape live. |
| **Pulse** · `sound/pulse` | `freq, amp, width: number` → `audio: audio` | Square wave with adjustable PWM. `width` 0 = symmetric square; 1 = thin spike. |
| **Noise** · `sound/noise` | `amp: number` → `audio: audio` | White / pink / brown noise. `type` param swaps the spectrum. |

## State

Cross-frame memory. The runtime breaks the topo cycle for these — their write input is gathered post-tick and emitted on the next frame.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **State** · `state/value` | `init, next: any` → `current: any` | One slot of cross-frame state for a single value. `init` seeds tick 0; `next` captured at end-of-tick; `current` emitted next tick. |
| **State\*** · `state/spread` | `init, next: any*` → `current: any*` | Same, for spreads. Walker trails, GoL grids, particle states. |
| **Read** · `state/read` | `init: any` → `current: any` | Split-state pattern — left half. Emits the value last written to the same slot. Falls back to `init` on frame 0. Auto-numbered `slot` badge shows the pairing. |
| **Write** · `state/write` | `next: any` → — | Split-state pattern — right half. Stashes `next` under the slot at end-of-tick. The matching Read emits it on the next tick. |

**Read/Write vs. single State**: dropping a `State*` node puts both pins on the same box, which forces one wire to bend backward when you wire up feedback. `Read` + `Write` are the same mechanism rendered as two boxes — drop Read on the left of your patch and Write on the right, and feedback flows strictly left-to-right with no visible loop. The two halves are paired by the slot number on each header.

## Region

Regions are scope containers. Inner nodes run with extra context (per-iteration values, conditions, cache hashes) supplied by the orchestrator. Ports are added on the frame's edges by dragging wires onto them; the compile step synthesises the matching splicer-in / splicer-out at runtime.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **ForEach** · `region/foreach` | dynamic frame ports → dynamic frame ports | Iterate over a spread. Inner nodes run once per slot. |
| **If** · `region/if` | `condition: boolean` + dynamic ports → dynamic ports | Run the inner scope when `condition` is true; otherwise emit empties / forward accumulator inits unchanged. |
| **Cache** · `region/cache` | dynamic ports → dynamic ports | Memoise the inner scope by structural hash of its inputs. Re-runs only when inputs change. |
| **Accumulator:number** · `region/accumulator/number` | outer `init: number`, inner `write: number` → inner `read: number`, outer `final: number` | State threaded between iterations. Init seeds the first iteration; `write` becomes the next iteration's `read`; the last `write` is exposed as `final` on the outside. |
| **Accumulator:boolean** · `region/accumulator/boolean` | outer `init: boolean`, inner `write: boolean` → inner `read: boolean`, outer `final: boolean` | As above, for booleans. |

### Internal (hidden from palette)

These exist so the runtime has a node to schedule for each region frame port. Compile synthesises them; the user never drops one manually.

- `region/splicer-in/{number,layer,boolean}` — receive an outer spread; deliver one slot per iteration.
- `region/splicer-out/{number,layer,boolean}` — collect one value per iteration into an outer spread.
