# Floret Nodes

Every built-in NodeDef, grouped by category (type-id prefix); the Nodes
browser groups them by role instead (below). Generated by hand from
`src/nodes/**` — keep in sync when adding or renaming nodes.

Format per row:

| Label · `type` | Inputs → Outputs | Description |

Port types: `number`, `boolean`, `string`, `vec2`, `color`, `mat3`,
`layer`, `style`, `audio`, `image`, `any`. A trailing `*` marks a spread-kind port.

**Pin kinds** — three flavours, distinguished visually:
- *single* (default): round pin, accepts one wire.
- *spread*: round pin, accepts one wire carrying a list.
- *multi* (input only): **taller pill-shaped pin**, accepts N wires; the
  runtime gathers them into a spread. Used by `transform/group` so you
  can drop many layer wires onto one input without a Stack chain.

**Spreads into single pins — per element** (native, patches saved from
format v4 on). The value nodes — Math, Vector Math, Compare, Logic,
Select, Convert, Map, Norm, Lerp, Clamp, Wrap, Step, Smoothstep, Vec2 /
Split / FromAngle / ToPolar, Color / Split / Set Alpha / Lerp Color /
Gradient (per `t`), Ease, Uniform / Gaussian / Wanderer, MIDI ↔ Freq,
String Length, Image Sample (per `x`, `y`) and the hidden single-op nodes
behind them — run **once per element** when a spread reaches a
single-value pin, the same rule as Expression: the longest spread sets the
count, shorter spreads (and single values) cycle, and an empty spread
empties the result. Every output then carries one value per element.
Lifting starts only when a pin carries two or more values: until then the
node runs exactly as before, an empty pin reading as "nothing" (so a
missing device or an upstream error still falls back to defaults). A
spread *output* (Linear, Grid, Range …) may be wired straight into such a
pin. **Smooth** and **Spring** keep their state per element (a new element
starts at its target). Delay Line, Trigger, Edge, Counter, LFO and the
draw / style / transform / text nodes still read slot 0 of a spread (wrap
them in a ForEach). Files saved before v4 keep their old behaviour: they
load with `legacySlot0` set, where those nodes read slot 0 of a spread and
a spread output wired into a single pin is dropped with a warning — saved
again, they stay that way.

`audio` is a persistent handle to a live p5.sound object kept alive in
the audio registry across frames. Wires of this type carry signal flow:
Source nodes (Oscillator, Noise, …) emit it; Processors (Filter, Gain,
…) consume and re-emit a processed version; the **Output** sink
terminates the chain. Per-frame compute updates parameters on the
existing audio object — the Web Audio nodes themselves only get
re-created when the node type changes or the editor node is deleted.

change a node's type id, ports or category (the tables below stay
grouped by category, i.e. by type-id prefix); searching still matches the
old category names and type ids.

**Op families.** Math, Vector Math, Compare, Logic, Statistics and
Convert, and in Lists Lookup, Sublist, Reorder and Combine, are one node
each with an `op` (Convert: `to`) dropdown; the pins follow the op. They
replace 82 single-op nodes (`math/mul`, `vec2/dot`, `logic/lt`,
`convert/to-int`, `spread/take` …), which stay loadable and
compute identically but are hidden from the browser — see each
section's *Legacy single-op nodes*. A search for an op's name ("mul",
"normalize", "xor") offers it directly and places the family node set
to that op.

## Time

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **Time** · `time/seconds` | — → `t, loop: number` | Seconds since runtime start, and `loop`: the phase 0..1 through the patch's loop length (File → Export Video / GIF… sets it). Build on `loop` and a recording of one loop repeats seamlessly. |
| **Frame** · `time/frame` | — → `frame: number` | Integer frame counter. |
| **Delta** · `time/delta` | `max: number` → `dt: number` | Seconds since the previous frame. `max` above 0 (native) caps it, e.g. 0.05, so motion doesn't jump after a stall; 0 (the default) leaves it alone. |
| **LFO** · `motion/lfo` | `shape, rate, offset, min, max, width: number, reset: boolean, count, spread, bpm, seed: number`, `sync` → `value, phase: number` | Oscillates between `min` and `max`, `rate` times a second (sine, triangle, saw, ramp-down, square, random, smooth-random); `count` > 1 gives that many staggered copies. `sync` loop: `rate` counts whole cycles per patch loop (at least one) and the phase follows the clock, so a recording of whole loops joins seamlessly — random shapes repeat every loop; `bpm` and `reset` don't apply. Native-only. |
| **Smooth** · `motion/smooth` | `value: any, rate: number` → `result: any` | Eases toward `value` (number, vec2 or colour). Over a spread (v4 files) every element eases on its own. |
| **Clock** · `time/clock` | `offset: number`, `zone` → `hours, minutes, seconds, day, month, year, weekday, yearPhase, days: number` | The wall clock, read every frame (effectful): the time of day in the computer's time `zone` (`local`, from the OS on macOS and Linux; elsewhere UTC) or `utc`, moved by `offset` hours (time travel, other cities). `hours` 0..24, `minutes` / `seconds` 0..60, all running on smoothly (fractions included); `day` 1..31, `month` 1..12, `year`, `weekday` 0 = Monday … 6 = Sunday, `yearPhase` 0..1 through the year, `days` since 1 January 1970 (for cycles longer than a day, e.g. the Moon's 29.53). Sample: `sys-clock`. Native-only. |
| **Beat** · `time/beat` | `bpm, steps, beats, swing, gate: number, run, reset: boolean, sync` → `step, phase, bar: number, gate, trigger: boolean, count: number` | A musical step clock: `bpm`, `beats` per bar, the bar cut into `steps`. `step` 0..steps−1, `phase` 0..1 through the step, `bar`, `gate` (on for the first `gate` fraction of a step), `trigger` (the frame a step starts), `count` (steps since the start). `swing` 0..1 delays every second step (1 = 3:1). `run` off pauses, `reset` restarts. A step due on a frame starts on it (summed frame times are snapped onto whole steps, so 6 steps a second at 60 fps is exactly one every 10 frames). `sync` `loop`: a whole number of bars fills the patch loop (tempo bends a little), so a recorded loop repeats seamlessly. Replaces `floor(t * 6) % 16`, `fract(t * 6) < 0.45`, `mod(ph + dt * bpm / 15, 16)` step counters. Effectful; state survives edits. Native-only. |

## Motion

Smoothing, easing and time-based shaping. (Ease, Smooth, Spring, LFO, Delay Line and Trigger are in the node browser's Animate group.)

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **Integrate** · `motion/integrate` | `rate, start: any*` (number / vec2 / colour), `run, reset: boolean*`, `limit` (+ `min, max: any*` unless `none`), `maxDt: number` → `value: any*, hit: boolean*` | `value += rate · dt` every frame, per element. Starts at `start`; `reset` (held) returns there; `run` off pauses. `limit`: `clamp` stops at `min` / `max`, `wrap` jumps round (phases, playheads, scrolling), `bounce` runs back and forth; `hit` = the frame it wraps, bounces or arrives. `dt` is capped at `maxDt` (0 = no cap). Changing `rate` never jumps, unlike `t × rate`. Replaces `ph + min(dt, 0.1) * rate`, `p + v * h`, `r ? 0 : min(1, g + dt / 9)`, `fract(s + t / 40)`. Effectful; state survives edits. Native-only. |
| **Envelope** · `motion/envelope` | `from` (`age: number*` or `trigger: boolean*`), shape pins (`time` / `attack, hold, time` / `frequency, time`: number*) → `value, age: number*, active: boolean*` | A shape in time after an event, per element. `shape`: `decay` (1 → 1 % at `time`), `attack-decay` (ease up over `attack`, `hold`, exponential decay over `time`), `fade` (linear ramps), `boing` (damped sine about 0 at `frequency` Hz, dying over `time`), `spring` (0 → 1 with overshoot, settled by `time`). `from` `age`: seconds since the event; `trigger`: times itself from each rising edge. Rests at 0 before the event (a spring at 1 once settled); `active` while moving. Replaces `exp(-4 * (t - b)) * sin(18 * (t - b))`, `1 - exp(-6 * a) * cos(15 * a)`, `clamp(1 - (t - l) * 1.6, 0, 1)`. Effectful; trigger times survive edits. Native-only. |

## Random

Seeded, deterministic noise and PRNGs. Wire `time/frame` into `seed` for per-frame variation, or a `region/foreach` iteration index for one value per slot.

**Patch seed** (native app): every seeded node — these, the spread shufflers / noise / Game of Life seed / random walk, Wind and Turbulence, Emitter and FromLayer, WalkerCluster and the LFO's random shapes — mixes the patch's seed into its own (`EvalCtx::seed`, `floret_engine::seed`). Seed 0, the default, leaves every node's seed as it is; **Vary** (Ctrl/⌘+Shift+R) re-rolls it for a new variation of the same patch. The seed and saved **presets** live in the `.flora` file (optional top-level `seed` / `presets`) and are edited in the Presets panel.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **Noise** · `noise/noise` | `pos: vec2*`, `x, y, scale, seed, octaves, falloff, warp, warpScale: number*`, `step: number` (+ `feature: string` in cellular mode, `angle: number*` in stripes mode) → `noise: number`, `flow, gradient: vec2` | 2D noise at (pos + (x, y)) · scale, per element over spreads. `mode`: perlin, simplex, value, cellular (Worley; `feature` F1 / F2 / F2-F1) or curl (`flow` = curl of Perlin fBm). Pattern fields in the same pins: checker (1 / 0 squares), stripes (+ `angle: number*`, radians; a smooth wave, one stripe per unit) and rings (round the origin); warp them for marble / wood / op art. `octaves` > 1 = fBm, `falloff` = amplitude ratio; `warp` / `warpScale` domain-warp the point. Perlin mode at defaults equals the old Perlin node, curl mode the old CurlNoise. Field modes (+ `center: vec2*, radius, weight: number*`): `radial` (Σ weight · (1 − (d/r)²)², 0 past the radius) and `gaussian` (Σ weight · e^(−(d/r)²)), measured in `pos` units (`scale` unused) — pressure highs / lows, metaballs, attractor maps. `gradient: vec2` (every mode): the slope per unit of `pos`, uphill (forward differences); steer Move with it. `step` above 0 (the last pin, every mode) takes it by central differences `step` units of `pos` either side instead: the slope at that scale, smoothing finer detail (a weather map's pressure slope over a few kilometres); 0, the default, is the local slope. ## Video

Video files as images (native app only). Frames come out on the `image` wire like any other image, so `draw/image` and the Image / Pixel nodes take them directly. MP4 / MOV with H.264 plays everywhere; on macOS anything QuickTime plays (HEVC, ProRes, …). Audio tracks are ignored. The file is referenced by path (pick it on the node), not copied into the patch.

Both nodes also play **image sequences**, numbered PNG / JPEG frames, at their `fps` pin (default 30; ignored for video files): pick one frame of a run and the rest are found (`name-0001.png, name-0002.png, …`, as the PNG-sequence export writes them; zero-padded numbers match their own width, unpadded ones any), or give a folder (every PNG / JPEG in natural order), a pattern (`name_####.png`, `name_%04d.png`, `name_%d.png`) or a list of frames one per line (paths or `data:` URLs — how a patch can carry a short sequence inside itself). Frames decode on the playback thread into the same bounded cache as video frames.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **VideoFile** · `video/file` | `url: string, play, loop: boolean, speed, scrub, fps: number` → `image: image, time, duration, width, height: number, ready: boolean` | Play a video file. `speed` is a rate (negative plays backwards). | **VideoFrameAt** · `video/frame-at` | `url: string, time, fps: number` → `image: image, duration, width, height: number, ready: boolean` | One frame of a video at `time` seconds, without playback: random access for stills, contact sheets or sensor-driven scrubbing in seconds. |

## State

Cross-frame memory. The runtime breaks the topo cycle for these — their write input is gathered post-tick and emitted on the next frame.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **State** · `state/value` | `init, next: any` → `current: any` | Legacy (hidden from the browser; old files still load): one slot of cross-frame state with `next` wired back into the same box. Use Write → Read instead. |
| **State\*** · `state/spread` | `init, next: any*` → `current: any*` | Legacy (hidden), same for spreads. Use Write\* → Read\* instead. |
| **Read** · `state/read` | `init: any` → `current: any` | Start of a feedback pair. Emits the value its Write (same `slot`) stored last frame; `init` on frame 0. Params: `slot` (the pairing), `name` (optional, shared with its Write). |
| **Write** · `state/write` | `next: any` → — | End of a feedback pair. Stores `next` at end of frame; its Read emits it next frame. Params: `slot`, `name`. `Read*` / `Write*` (`state/read-spread`, `state/write-spread`) are the spread versions. |

**Feedback: Write → Read.** Patches flow left to right; the only way a value crosses frames is a Write at the end of the flow and its paired Read at the start (never a wire back into an earlier node, never a single State box with `next` wired back). The two halves are paired by their slot, kept underneath; the header shows `#slot`, or the pair's name once it has one (`Write · ball position`). In the editor, placing a Write also places its Read (to the left of the flow, at the same height) and vice versa, on a slot of its own, both selected; double-click either header (or "Name pair…" in its menu) to name the pair, which names both. Selecting a half draws a dashed arc to its partner, and hovering one lights the other. Deleting a Write deletes its Read(s); deleting a Read deletes its Write unless another Read of it stays. Duplicated or pasted halves get a fresh slot, and a lone copied half gets a new partner. The compiler warns about a Read with no Write, a Write with no Read, and two Writes on one slot.

Regions are scope containers. Inner nodes run with extra context (per-iteration values, conditions, cache hashes) supplied by the orchestrator. Ports are added on the frame's edges by dragging wires onto them; the compile step synthesises the matching splicer-in / splicer-out at runtime.

| **Move** · `particles/move` | `position, velocity, acceleration: vec2*, drag, maxSpeed, radius: number*, edge, center, size: vec2` (+ `restitution: number*` in bounce, `reset: boolean*` in run mode), `timeScale` → `position, velocity: vec2*, hit: boolean*, normal: vec2*` | Kinematics on plain lists, no buffers: semi-implicit Euler with `acceleration`, `drag` (per second) and `maxSpeed`; the box (`size` 0 × 0 = the canvas) `wrap`s (things leave whole), `bounce`s (`restitution`), `clamp`s or not (`none`), allowing for each `radius`. `run` keeps its own state from the inputs (spread growth adds movers; `reset` per element respawns); `step` moves the inputs one frame (for a State loop). `hit` / `normal`: the wall touched this frame. dt capped at 0.1 s. ### Forces

All output a `force` value plugged into a World's `forces` input (global) or an Emitter's `localForces` (per-emitter). Shaped forces also expose a `viz` layer output for debugging (toggle `showViz`).

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **Gravity** · `force/gravity` | `direction, strength` → `force` | Uniform vector, scaled by particle mass. Use for *additional* gravity beyond what's on World. |
| **Drag** · `force/drag` | `strength` → `force` | Velocity-proportional damping. Per-particle, composable. |
| **Attractor** · `force/attractor` | `center, strength, radius, falloff (C), showViz (C)` → `force, viz` | Radial pull. Negative strength = repulsion. Falloff baked at compile. |
| **Repulsor** · `force/repulsor` | `center, strength, radius, falloff (C), showViz (C)` → `force, viz` | Radial push. (Attractor with inverted semantics.) |
| **Vortex** · `force/vortex` | `center, axisStrength, pull, radius, falloff (C), showViz (C)` → `force, viz` | Rotational + optional radial pull. Counter-clockwise when `axisStrength > 0`. |
| **Wind** · `force/wind` | `direction, strength, noise, seed (C)` → `force` | Directional force with Perlin variation. Mass-independent. |
| **Turbulence** · `force/turbulence` | `scale, speed, strength, seed (C)` → `force` | 2D Perlin noise field. Time drifts the field. ~5–10× the cost of gravity per particle. |

### Colliders

All output a `collider` value plugged into a World's `colliders` input. Modes: `bounce` (reflect velocity, scaled by `restitution`), `kill` (free the slot), `absorb` (zero velocity in place). `inverted` flips inside/outside.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **Circle** · `collider/circle` | `center, radius, mode (C), restitution, inverted (C)` → `collider` | Analytic circle. Cheap. |
| **Rect** · `collider/rect` | `center, size, mode (C), restitution, inverted (C)` → `collider` | Axis-aligned rectangle. Cheap. |
| **FromLayer** · `collider/from-layer` | `layer, mode (C), restitution, inverted (C)` → `collider` | Build a collider from any shape (rect / ellipse / triangle / polygon). Polygon bounce uses centroid-normal approximation. |

### Simulation

One stateful node with a `mode` dropdown; its pins follow the mode. It steps 60 times per second of frame time (at most 3 steps a frame), so the same seed and frame times give the same result. A rising edge on `reset` starts over; so does a new `seed` (and, per mode, a new size / count / grid). Native only. Growth and reaction keep their state through edits of the patch. Samples: `sim-flocking`, `sim-slime-mould`, `sim-dla-coral`, `sim-cloth`, `sim-differential-growth`, `sim-reaction-diffusion`.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **Simulation** · `particles/simulation` | per `mode` (below) → `layer, points*, values*, from*, to*, image` | `layer` draws the simulation; `points` / `values` / `from`, `to` are there to draw your own; `image` is the physarum trail map or the reaction–diffusion picture (1×1 placeholder otherwise). `colors*` ramps shapes along `values`. |

| Mode | Inputs | Outputs |
|---|---|---|
| `flocking` | `count, size, maxSpeed, separation, alignment, cohesion, radius, target, food*, attract, scale, style, colors*, seed, reset` | Boids on a wrapping `size` field: darts on `layer`; `values` = heading (radians); `from`→`to` = 0.1 s of velocity. `attract` steers them to `target` or, while `food*` holds points, each boid to the food point nearest it (the short way round the field; every boid against every point, so keep food to hundreds). A changing `count` adds or drops boids without starting over, so it can be a population. |
| `physarum` | `agents, size, resolution, sensorAngle, sensorDistance, turnAngle, stepSize, deposit, decay, diffuse, food*, colors*, seed, reset` | Slime-mould agents on a `resolution`-cell trail map (angles in degrees, distances in cells; trail saturates at 1). `image` and `layer` show the map: white→clear with no `colors`, one colour→that colour, several→a ramp from empty to dense. `food*` points keep the trail full. |
| `dla` | `count, size, radius, rate, stickiness, seeds*, style, colors*, seed, reset` | Walkers stick to a cluster grown from `seeds*` (the origin if none), `rate` per second up to `count`. Lines from each particle to its parent; `values` = growth order 0..1. |
| `cloth` | `cols, rows, size, pos, pin, gravity, wind, stiffness, iterations, damping, tear, pointer, grab, style, colors*, reset` | Verlet spring mesh; `pin` = top / corners / left / none (pins follow `pos`). `tear` > 0 breaks springs stretched past `tear` × rest. Holding `grab` drags the point nearest `pointer`. `values` = stretch; springs on `layer` and `from`→`to`. |
| `growth` | `shape*, radius, size, maxNodes, repel, force, align, maxEdge, grow, speed, style, colors*, seed, reset` | Differential growth: a curve (the first outline of `shape`, closed or open, else a circle of `radius`) whose nodes push apart within `repel` (× `force`), pull `align` of the way to their neighbours' middle and move at most `speed` a step; `grow` new nodes a second go in at random edges and edges longer than `maxEdge` split, up to `maxNodes` (8000 at most), so it folds like coral or a brain. Stays inside `size`. One path on `layer` (the style's fill too); with `colors` the edges ramp by age. `values` = age 0..1; `from`→`to` = edges. |
| `reaction` | `size, resolution, preset, (feed, kill), rateA, rateB, speed, seed image, paint*, colors*, seed, reset` | Gray–Scott reaction–diffusion (Karl Sims's formulation) on a wrapping grid `resolution` cells along `size`'s long side (512 at most), on the CPU. `preset`: coral, mitosis, fingerprints, worms, maze, spots, waves, or custom (`feed`, `kill` pins). `rateA` / `rateB`: diffusion; `speed`: iterations a step (40 at most). B starts where `seed image` is bright (luminance × alpha > ½, stretched over `size`) or in a few random spots; `paint*` points keep adding it. `image` / `layer`: B's concentration, coloured like physarum's map. For full-screen resolution use the Shader node's feedback buffers. |

## Geometry

Native-only generators and shape operations. The polygon nodes share their outputs: `shape` (all polygons in one layer), one layer per polygon, `points` (every ring's corners, flat) and `counts` (corners per ring — pair them with **AtGroup** to pick one ring). Layers are read as outlines: polygons, paths, lines, rects, ellipses, arcs, triangles, quads, glyphs (`text/glyphs`) and text (`draw/text`), with group transforms applied. A dropdown picks the mode; the pins follow it.

| Label · type | Inputs → Outputs | Description |
|---|---|---|
| **Scatter** · `geometry/scatter` | `center, size: vec2, shape: layer*` + mode pins (`distance` / `count` / `spacing, jitter` / `points`), `relax`, `seed` → `points: vec2*` | Points over a rectangle or inside a wired shape. Modes: `poisson` (no two closer than `distance`), `random`, `jittered-grid` (one per `spacing` cell, moved up to `jitter` of a cell), `halton` (low-discrepancy, shifted by the seed), `relax` (the wired `points`). `relax` runs that many passes of Lloyd relaxation (each point to the centre of its Voronoi cell, up to 100): clumps and gaps even out into an organic, even spread with an exact count. `stipple` (`density: image, count, gamma, invert`): `count` points gathered where the image (stretched over the area) is dark — light with `invert`, `gamma` > 1 for more contrast — then relaxed by weighted Lloyd passes (Secord's weighted Voronoi stippling) into an even, hand-stippled grain. Same seed, same points. |
| **Cells** · `geometry/cells` | `points: vec2*, center, size: vec2` (voronoi, subdivide), `depth, chance, minSize, ratio, quad, seed` (subdivide), `gap: number, colors: color*, style` → `shape: layer, cells: layer*, points: vec2*, counts: number*, centers: vec2*, depth: number*` | Voronoi cells (clipped to the rectangle), Delaunay triangles or the convex hull of a points spread. `gap` leaves space between neighbours; `colors` fills polygon i with colour i (cycled). `subdivide`: recursive splits of the rectangle (Mondrian, quadtree) — in two across the longer side more often than not, or in four with `quad`; after the first split each part splits again with probability `chance`, down to `depth` levels, never thinner than `minSize`, cuts up to `ratio` (0..1) away from the middle; with `points` wired a part splits while it holds more than one of them (a quadtree / k-d tree of the points). Same `seed`, same splits; `colors` are picked per rectangle at random (repeat one to make it likelier); `depth` out = each rectangle's level (0 in the other modes). |
| **Path Ops** · `geometry/path-ops` | `points: vec2*, closed: boolean, path: layer*` + mode pins (`spacing` / `iterations` / `tolerance` / `distance, join`), `style` → `shape: layer, layers: layer*, points: vec2*, counts: number*` | Reshape a point list or every outline of a layer. Modes: `resample` (even spacing), `smooth` (Chaikin), `subdivide` (midpoints), `simplify` (Ramer–Douglas–Peucker), `offset` (grow / shrink areas with round, miter or bevel joins; open paths shift sideways), `round-corners` (radius: each corner an arc, limited by the edges), `thicken` (width, cap, join: a stroke's outline as filled polygons, in the stroke's colour), `wave` (amplitude, wavelength, phase: a sine along the normals, whole waves round closed shapes), `noise` (amount, scale, seed, phase: Perlin wobble), `twist` (angle, radius, center: a swirl that fades out at radius), `explode` (distance: every edge its own piece on `layers`, pushed out from the centre, in the fill's colour). wave / noise / twist resample every `detail` units first; their `phase` loops at whole numbers. Shapes from a layer keep their style unless `style` is wired. |
| **Shape Boolean** · `geometry/boolean` | `a, b: layer*, style` → `shape: layer, layers: layer*, points: vec2*, counts: number*` | `union`, `intersect`, `subtract` (a − b) or `xor` of the filled areas of two layers (nonzero winding; lines ignored), holes included. With only `a` wired, `union` merges its shapes. |
| **L-System** · `geometry/lsystem` | `axiom, rules: string, iterations, angle, step, fit: number, position: vec2, heading, jitter, seed: number, style` → `shape: layer, layers: layer*, points: vec2*, counts: number*` | Rewrite `axiom` by `rules` (`X=…`, separated by `;`) `iterations` times and draw it with a turtle: `F` `G` draw, `f` `g` move, `+` `-` turn by `angle`°, `\|` turns round, `[` `]` branch. `fit` > 0 scales the drawing into a `fit`-wide box centred on `position`. `jitter` randomises every turn (by `seed`). |
| **Trim Path** · `geometry/trim` | `points: vec2*, closed: boolean, path: layer*, start, end, offset: number, style` → `shape: layer, layers: layer*, points: vec2*, counts: number*, heads: vec2*, angles: number*` | Draw-on / write-on: only the part of each outline between `start` and `end` (0..1 of its arc length), slid round by `offset` (wraps; a closed path carries on round its start). Modes: `each` trims every outline at once; `sequence` lays them end to end and trims the run, so they draw one after another (handwriting glyph outlines). Pieces are lines: a filled shape strokes in its fill colour unless `style` is wired. `heads` / `angles`: where each drawing end is and which way it heads (one for `sequence`), for a pen tip or arrowhead. |
| **Shape Morph** · `geometry/morph` | `a, b: layer*, t, points: number, style` → `shape: layer, layers: layer*, points: vec2*, counts: number*` | Blend `a`'s outlines into `b`'s by `t` (0 = a, 1 = b). Outer shapes pair with outer shapes and holes with holes, in order; a contour with no partner shrinks to (grows from) its centre. Pairs are resampled to `points` each (0 = about one per 4 units) and lined up (same direction, best start point) so blends don't twist; open and closed mix. Fill / stroke colours and stroke weight blend too, unless `style` is wired. |
| **Connect Points** · `geometry/connect` | `points: vec2*` + mode pins (`distance, maxLinks` / `neighbours, distance`), `fade, taper: number, colors: color*, colorBy: string, style` → `shape: layer, from, to: vec2*, strength: number*` | Lines between nearby points (plexus). `distance`: every pair closer than `distance`, each point keeping at most `maxLinks` (shortest first; 0 = no limit). `nearest`: each point to its `neighbours` nearest (within `distance` when > 0). `strength` falls from 1 (touching) to 0 (at the reach); `fade` takes that much off a line's alpha and `taper` off its width. A wired `colors` spread colours the lines: `colorBy` `points` gives point i colour i (cycled) and draws each line as a gradient between its ends' colours; `length` runs the colours as a palette from the shortest lines (first) to those at the reach (last). A uniform grid keeps thousands of points fast; at most 100 000 lines. |
| **Curve** · `geometry/curve` | `count, center, radius, phase, rotation` + mode pins (`a, b` / `n, d` / `R, r, d, laps` / `turns, inner` / `points, inner` / `m, n1, n2, n3`), `style` → `shape: layer, points: vec2*, tangents: number*` | Parametric curves: `lissajous`, `rose`, `hypotrochoid`, `epitrochoid`, `spiral`, `log-spiral`, `star`, `superformula`. `count` points fitted to `radius` round `center` (Lissajous fills the square), turned by `rotation`; closed curves run round exactly once (period from the ratios, up to 64 turns) and close their path; spirals are open, `inner` → `radius`. Hypo- / epitrochoid `laps` (0, the default: one closed period) above 0 runs the pen round that many times instead, as an open path (point i at i / count of the laps) — a Spirograph drawn for as long as you like. `phase` 0..1 is one seamless animation cycle (figures morph, roses / stars / superformula turn one symmetry step, spirals one turn). `tangents`: direction of travel (radians). Replaces `vec2(cos(u * tau), sin(u * tau)) * (… abs(cos(petals / 2 * u * tau)))`, `vec2(sin(tau * l * 3), sin(tau * l * 4))` and Spirograph formulas. Native-only. |
| **Plot** · `geometry/plot` | `values: number*, center, size: vec2, range` (+ `min, max` when `fixed`), `baseline` (area, bars), `gap` (bars), `style` → `shape: layer, points, base: vec2*` | Values as a chart in a box: `line`, `area` (closed down to `baseline`: filled hills, mountain ridges) or `bars`. Replaces `vec2(-330 + 660 * index / 239, 292 - 108 * v)` chart points and the two extra corner points (`index == 100 ? vec2(400, 260) : …`) that close a ridge. Native-only. |
| **Hit Test** · `geometry/hit-test` | `points: vec2*` + mode pins (`centers, sizes: vec2*` / `centers: vec2*, radii: number*` / `shapes: layer*`), `margin: number` → `inside: boolean*, index, hits: number*` | Points against `rects`, `circles` or a `layer`'s shapes (each drawn shape one; holes respected; lines by their stroke). `margin` grows (shrinks when negative) every shape. Per point `inside` and `index` (first shape, −1 none); per shape `hits` (points inside). Replaces `abs(c.x - q.x) <= 37 && abs(c.y - q.y) <= 17`, `distance(q, m) < 10`, grid-cell maths like `floor((m.y + 174) / 36) * 16 + floor((m.x + 288) / 36)`. Native-only. |
| **Contours** · `geometry/contours` | mode pins (`values: number*, cols` / `points: vec2*, radius: number*, cell` / `image` / `shape: layer*, cell`), `center, size: vec2, threshold, levels, step: number, colors: color*, style` → `shape: layer, layers: layer*, points: vec2*, counts: number*, levels: number*` | Isolines of a field as closed outlines (marching squares). `field`: a spread of `values`, `cols` a row, over the rectangle (e.g. noise on Grid positions: topographic lines). `points`: metaballs, Σ radius² / distance², sampled every `cell` units. `image`: brightness × alpha (0..1) of an image centred on `center` at `size` (0 = its pixel size). `shape`: distance from the outlines of a wired layer (text, shapes; open paths by distance only), sampled every `cell` units: the levels are distances, 0 = the outline, outward positive, negative inside, and outer rings are drawn underneath, so filled rings stack into contour-map bands round a word. | **Layout** · `geometry/layout` | `count: number, center: vec2` + mode pins (`cols, spacing: vec2` / `radius, start, sweep` / `spacing` / `points: vec2*, closed, path: layer*`), `duration, stagger: number, easing: string, reset: boolean` → `positions: vec2*, angles, scales: number*, progress: number` | Arrange `count` items as a `grid` (`cols`, 0 = square-ish), a `ring` (a full turn, or an arc of `sweep` with items on both ends; angles point outwards), a phyllotaxis `spiral` (equal area per item) or evenly along a `path` (a layer's outlines end to end, or a `points` polyline; angles follow it). | **Tiles** · `geometry/tiles` | `cols, rows: number, size: number, center: vec2` + mode pins (`tiles, noise` / `sockets, closed`), `seed, colors: color*, style` → `shape: layer, layers: layer*, centers: vec2*, tiles, angles: number*` | A grid of tiles that read as one pattern (at most 64 a side). `truchet`: every cell takes a turn of a `tiles` set — `arcs` (two quarter circles: meandering loops), `diagonals` (10 PRINT maze), `triangles` (half squares) — at random, or with `noise` > 0 following Perlin noise at that scale per cell so turns clump. `wfc`: wave function collapse (simple tiled model) over edge-matched tiles: `sockets` lists them as four characters for the north, east, south, west edges (`0` = nothing, e.g. `1100` a corner; `*weight` makes one likelier); every tile comes in its four turns, neighbours must match where they meet, `closed` keeps the outer edges empty so no path runs off the grid; a contradiction restarts (12 tries, then a warning).
