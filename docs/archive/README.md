# Archive

These describe the earlier web version of Floret or past planning, kept for
history, not current documentation. For how Floret works today, see the
[README](../../README.md), [NODES.md](../../NODES.md) and the
[beta tester guide](../beta-testing.md).

| File | What it is |
|---|---|
| `CONCEPTS.md` | The core-concepts map of the web version's code. |
| `Plans.txt` | A consistency-pass plan for the node set. |
| `floret-landing-spec.md` | A design spec for a landing page. |
| `gpu-renderer-migration.md` | The web version's move to a GPU renderer. |
| `native-app-transition.md` | Planning for the move to the native app. |
| `plan-feature-complete.md` | The feature-complete plan, including its "Ground rules" for adding nodes and samples. |
| `feature-complete-summary.md` | What the feature-complete plan delivered. |
| `sample-review.md` | An earlier review of the Library samples. |
| `design-specs/` | Design specs for individual features. |
